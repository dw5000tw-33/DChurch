# 東海靈糧堂｜破冰遊戲素材

這裡分享教會聚會可使用的破冰遊戲素材。

## 恩典大風吹

「恩典大風吹｜隨機題目」是一個可在聚會中使用的互動網頁，包含隨機題目、小任務、倒數計時與背景音樂。

[開啟恩典大風吹遊戲網頁](./恩典大風吹_隨機題目.html)

## 森林裡的狐狸

「森林裡的狐狸」是一個幸福小組破冰互動網頁，包含五張故事圖卡、背景音樂與八分鐘倒數計時，適合帶領大家一起聽故事、參與互動。

[開啟森林裡的狐狸互動網頁](./幸福小組_森林裡的狐狸_互動網頁.html)
## 成長班見證｜信仰・預備・交託

見證分享稿頁面，含十分鐘計時、上台閱讀模式與三張早安圖。

[開啟見證分享稿](./testimony/index.html)

## 每日貼文分享工作台（設計預覽 v0.1）

整理教會每日分享文章的前台介面。三篇禱告合併勾選，其他來源可獨立勾選；支援人工查證原文連結、LINE 全文預覽與複製。第一版使用示範資料，尚未接入正式來源。
